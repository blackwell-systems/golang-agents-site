Start here if you are new to agents or to LLM (large language model) APIs.
The pages build on each other in the order listed, and each one points at runnable Go code.
The last group, Go in depth, is reference on the Go an agent uses, and it assumes you know goroutines, channels, and generics.
If those are new, continue along the reading path and come back to these pages later.
