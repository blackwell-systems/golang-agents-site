one turn until an answer or a limit

  1. Build the request

    Decide what the model sees: instructions, the conversation so far, tool results, and the tools it may call.

  2. Call the model

    Send the request and read the reply, with a deadline and a count of what it cost.

  3. Run the tools

    Carry out the calls the model asked for, and add each result to the conversation.

  4. Decide

    Stop with an answer, stop at a limit, or go around again.

Then back to stage 1, with everything that just happened in the conversation.
